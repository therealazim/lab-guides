# KU-KMI LUPIC LAB PROJECT

Laboratory Equipment Guide System with multilingual support (English, Uzbek, Karakalpak, Russian, Korean).

## How to Use

### Option 1: Deploy to Netlify (Easiest)

1. Download all files from this repository
2. Go to [netlify.com](https://netlify.com) and log in
3. Drag and drop the project folder or the `dist/` folder onto Netlify
4. Your site will be live in seconds!

### Option 2: Run Locally

```bash
pnpm install
pnpm dev
```
